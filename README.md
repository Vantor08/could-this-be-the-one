# Vallore SuperBalance - Shopify theme
Rebuilt from the live preview. Homepage + product page both show the custom Vallore design:
- Homepage (/) shows the brand/home view.
- Product page (/products/...) shows the full product (buy box) view.
Other templates (cart, collection, customer pages) are minimal working stubs.

## Connect via GitHub
Put the CONTENTS of this folder at the repo root, then Shopify admin -> Online Store -> Themes -> Add from GitHub.

## Videos (not in repo)
Upload each ritual video to Shopify (Content > Files), copy its URL, and paste into the top of
sections/main-page.liquid (ritual_video_1..5). The video section stays hidden until a URL is set.
